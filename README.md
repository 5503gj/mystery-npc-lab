# 剧本杀游戏实验室 · AI NPC 关系互动原型

这是一个原创的剧本杀网页原型，不包含第三方剧本、音频、海报或角色原文。

## 当前 Demo

- 一人玩家 + 3 个 NPC
- NPC 询问与关键词响应
- 线索解锁与调查阶段
- 嫌疑人指认与多结局
- 无需 API Key，可离线体验

## 本地运行

在本目录执行纯离线版本：

```powershell
python -m http.server 7863
```

然后打开 http://127.0.0.1:7863/。离线版本使用内置规则引擎。

## 接入本地小模型

推荐使用 Ollama 运行轻量中文模型。Qwen 官方仓库给出了本地 Ollama 运行方式，例如 `qwen2.5:3b`；本项目不会自动下载模型，避免占用大量磁盘和网络流量。

```powershell
ollama pull qwen2.5:latest
.\run.ps1
```

然后打开 http://127.0.0.1:7865/。服务会调用 Ollama 的本地 `/api/chat` 接口；如果模型没有运行，网页仍会回退到规则引擎。

当前实现的“智能回答”由四层组成：最近对话记忆、NPC 人设、已公开线索、模型回复约束。真相和线索解锁仍由程序状态机判断，避免模型随口改写案件事实。

## Agent 工作流

对话请求会先经过一个可解释的本地工作流：

```text
用户问题 → 意图识别 → 安全上下文工具 → 本地模型生成 → 规则边界校验 → 回复
```

服务端同时保留 `/api/chat` 兼容入口，并提供 `/api/agent` 入口。接口返回 `trace_id`、执行步骤、工具结果摘要和 guardrails，便于演示 Agent 的状态、工具和观测边界。当前版本不搭建数据库，状态由网页会话维护；它适合本地 Demo，不宣称多用户云端持久化。

# Mystery NPC Lab

一个本地运行的 NPC 关系驱动互动体验原型，包含原创规则引擎和可选的本地小模型接入。

## 当前场景

- `http://127.0.0.1:7865/ye-pusa.html`：野菩萨关系对话场景
- `http://127.0.0.1:7865/liufang.html`：流芳情感本关系对话场景

项目定位是可扩展的剧本杀游戏框架：不同剧本可以接入独立角色卡、NPC 人设、人物关系、场景流程和线索规则。同一个 NPC 面对不同对象时，会使用不同语气、信息边界和情感目标。

当前《流芳》场景包含 6 个可选角色、5 位核心 NPC、4 幕流程和关系对象切换；《野菩萨》作为另一套情感关系场景保留在同一实验室中。

## 启动

```powershell
H:\code\python\python.exe server.py
```

没有 Ollama 时，网页使用内置关系规则；安装并运行 `qwen2.5:latest` 后，网页会把人物关系和当前场景交给本地模型生成更自然的短回复。

## 内容边界

本项目只保留根据本地资料提炼的角色规则，不放入剧本原文、扫描件或线索图片。仓库中的各场景是关系机制演示，不是剧本全文电子化。公开使用前，请确认剧本版权与网页展示/改编授权。
